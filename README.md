# Royal Cut Plano

Marketing demo site for **Royal Cut Plano** — barbershop at 3013 Spring Creek Pkwy Suite #400, Plano, TX 75023.

Built from public Google Maps / Booksy listings. Independent demo — not the shop’s official site unless adopted.

## Dev

```bash
npm install
npm run dev
npm run build
npm start
```

## Deploy

Static Vite build served with `serve`. Railway: 0.25 vCPU / 0.25 GB, serverless sleep OK.
